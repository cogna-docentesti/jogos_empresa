# Fontes da arte

`references/concepts/` guarda os cinco concepts aprovados. `editable/` recebe as fontes SVG/código e arquivos de trabalho; `previews/` recebe provas de montagem e QA visual. Essas pastas ficam fora de `Assets` para o Unity importar apenas a arte final.

Consulte [o plano de produção](../docs/art/PLANO-DE-ARTE.html) e [o manifesto](../docs/art/manifest.json) antes de criar um lote. Os PNGs finais permanecem em `Assets/Art/new/`, no caminho individual de cada asset.
