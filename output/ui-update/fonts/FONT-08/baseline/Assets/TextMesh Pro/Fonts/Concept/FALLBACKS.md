# FONT-03 — finite fallback coverage

Roboto and Roboto Condensed remain the primary production families. Their six static faces are the files documented by FONT-02. The FONT-03 TMP assets bake the 342 supported codepoints from the 536-codepoint declared corpus.

The remaining characters use explicit, finite, static fallback assets:

| Source | Real weights | Baked coverage | License |
| --- | --- | --- | --- |
| Noto Sans | Regular 400, Bold 700 | Only the 190 Latin gaps listed in `docs/ui-update/font-assets.json` | SIL Open Font License 1.1, original `Sources/NotoSans/OFL.txt` |
| Noto Sans Math | Regular 400 | U+2190, U+2191, U+2192, U+2193 only | SIL Open Font License 1.1, original `Sources/NotoSansMath/OFL.txt` |

Both families were acquired from the official [Google Fonts repository](https://github.com/google/fonts) at revision `1c627bfa375fc51cf86fabeca4f6e08a95f0aa5c`. Original source binaries, copyright/license notices and metadata are preserved under `Sources/`. URLs and SHA-256 hashes are recorded in the font source and asset manifests. Noto Sans static instances use `wdth=100` and `wght=400/700`, generated by fontTools 4.60.1 using `tools/ui/font03_support.py`. Font names identify the original families and actual weights; no outlines are artificially emboldened.

The fallback asset tables have no further fallback entries. Bold resolves to a real Noto Sans Bold; Medium maps to Noto Sans Regular and SemiBold to Noto Sans Bold for these exceptional Latin glyphs. All weights use the same four real Math arrows without synthetic dilation. No source font from the operating system, Inter, Inter Tight or Liberation Sans participates in the declared font graph.

These static assets cannot grow or add other Noto glyphs at runtime. Other scripts, emoji and codepoints outside the declared corpus are not homologated. A future coverage extension must be explicit and revalidated. The global TMP defaults and the UI theme are integration work for FONT-04 onward.

Regeneration runs in the existing Unity Editor through `Tools > Jogos de Empresa > FONT-03 > Generate and validate assets`. The generator updates font assets and their material/atlas subassets in place. Player references are held by `Assets/Resources/UI/ConceptFontSet.asset`; runtime rendering uses baked atlas data.
